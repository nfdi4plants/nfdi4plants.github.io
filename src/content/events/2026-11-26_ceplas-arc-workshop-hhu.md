## Goals

- First steps into the <a href="https://arc-rdm.org/" target="_blank">ARC</a> ecosystem
- Annotate datasets with structured metadata
- Share them via the <a href="https://git.nfdi4plants.org" target="_blank">DataHUB</a>

### Checklist for participants

Please prepare the following **before** the workshop.

- Sign up for a [DataPLANT user account](https://register.nfdi4plants.org/)
- Install [ARCitISA](https://nfdi4plants.github.io/nfdi4plants.knowledgebase/arcitisa/installation/)
- Bring a laptop with internet access in the workshop location and ARCitISA installed
