The ARCitISA bundles many DataPLANT services into a single GUI application.
Create and edit your ARCs.
Synchronize ARCs with the [PLANTdataHUB](/resources/arc-data-hub#plant-data-hub).
Enrich Assays and Studies with metadata from ontologies in a familiar, spreadsheet-like work environment. 
Incrementally increase metadata quality of an [ARC Scaffold](https://arc-rdm.org/details/arc-representation/#arc-scaffold).
Select validation packages to use in PLANTdataHUB.
